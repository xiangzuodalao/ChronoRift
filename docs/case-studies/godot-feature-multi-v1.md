**实验接入与未执行部分**

预定试验顺序按入选题目交替首发组别，逐 trial 串行执行，每组每题一次，最多六次。入口为每次试验创建新 Session、candidate 和 state，使用独占批次标记防止重跑，并在启动前复查冻结文件；最终候选仅在 writer 清理后评分。端到端时间从父进程启动 Host 到子进程退出另行记录，20 分钟调查截止包含启动开销，截止后的清理耗时仍保留。SDK 请求累计耗时和跨代理锁等待不能直接相加当作关键路径。
